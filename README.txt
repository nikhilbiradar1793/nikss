NIKHIL BIRADAR PORTFOLIO — FLASK PROJECT

Folder structure:
app.py
requirements.txt
templates/index.html
static/css/style.css
static/images/profile.jpg       (your own portrait photo)
static/images/nikss-logo.png    (your NIKSS Coding Hub logo)

Run locally:
1. Open terminal in this project folder.
2. Run: pip install -r requirements.txt
3. Run: python app.py
4. Open: http://127.0.0.1:5000

Render:
Build command: pip install -r requirements.txt
Start command: gunicorn app:app

IMPORTANT:
Place your own portrait at static/images/profile.jpg.
Place your channel logo at static/images/nikss-logo.png.
The screenshot supplied was used as the design reference, not as your personal profile photo.
